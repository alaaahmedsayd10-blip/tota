# يلا سيتي — Yalla City

مشروع لعبة مدينة 2D مناسب للتطوير على أندرويد. يحتوي المستودع على نموذج ويب بسيط للتجربة من الهاتف، وملفات مشروع Godot كبداية لتطبيق أندرويد.

## تجربة النموذج على الهاتف
افتح `index.html` عبر استضافة صفحات GitHub بعد تفعيل Pages من Settings → Pages واختيار GitHub Actions أو نشر الفرع `main` حسب الإعداد المتاح. النموذج يحتوي على شخصية، مبانٍ، عصا تحكم تعمل باللمس، وعملات تجمعها أثناء الحركة.

## مشروع Godot
افتح `project.godot` باستخدام Godot 4.3 أو أحدث. المشروع نموذج أولي وليس لعبة نهائية. يلزم اختباره داخل المحرك وتجهيز تصدير Android قبل إنتاج APK. اللعب الجماعي الحقيقي يحتاج خادمًا ولم يتم تنفيذه بعد.

## ملفات المشروع
- `index.html`: نموذج قابل للعب في المتصفح.
- `project.godot`: إعدادات مشروع Godot.
- `scenes/`: المشاهد الرئيسية والشخصية.
- `scripts/`: منطق المدينة والتحكم والرسم.
